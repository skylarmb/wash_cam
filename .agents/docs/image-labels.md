# Image labels

`db/labels.sqlite3` contains the `image_labels` table. Each row stores the current verified labels for one image. `image_path` is the primary key and holds a path relative to `tmp/images/`. `metadata` stores a valid JSON object as text. `verified_at` stores the UTC verification time and defaults to the insertion time. Verification covers the entire image. Updates must set the new verification time explicitly.

The metadata convention uses `vehicles.bays`, an array of entries with stable `bay_id` values and flexible label fields. The dashboard saves `vehicle_count` for wash bays `bay_0` through `bay_4` (leftmost first) and the vacuum station `vac_0`. Zero means an empty bay. An omitted bay has not been labeled. The database requires an object at the JSON root but does not enforce fields or bay IDs. An absent row means no verified labels have been saved.

`db/migrations/001_image_labels.sql` creates the schema. `wash-cam migrate` (`wash_cam.db.migrate`) creates or upgrades the database by applying numbered migrations newer than `PRAGMA user_version`. The database and captures live only on the server (Mac mini); git tracks the migrations and ignores the database. The dashboard reads and saves counts through `/api/labels`. Previous/Next saves the current counts only when the image already has a row or its counts were edited; browsing past an unlabeled, untouched image creates no row, and only an edit or the Save button creates one. A dashboard save replaces only `vehicles`, keeps every other metadata key (including an agent row's `labeled_by`, `uncertain_bays`, and `notes`), and updates the verification time; it never adds or removes `labeled_by` and never implies a human review. Human review of agent rows (`reviewed_by`) is not designed yet: it will be when a human starts reviewing. Detector output goes to the separate `image_detections` table (see `detection-watcher.md`) and never into `image_labels`. Labels written by a labeling agent that judges each image itself are allowed, but only through `wash-cam label-import`, which records `labeled_by` (see `labeling.md`); rows without `labeled_by` are human labels, and the importer never overwrites them. A later human check of an agent label records `reviewed_by`.
