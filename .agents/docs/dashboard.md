# Dashboard

Run `uv run wash-cam dashboard`. The server listens on all IPv4 interfaces at port 8000. Open http://127.0.0.1:8000 locally or `http://<host-ip>:8000` from another computer. The Mac Mini dashboard is at http://10.0.4.25:8000. The server restarts automatically when Python source files change. Press Ctrl+C to stop the server. The Live view tab at `/` reloads every 30 seconds. It shows the JPEG with the latest timestamp filename from `tmp/images/`. A missing or empty directory shows `No images yet`.

The Data labeling tab at `/labeling` selects an image and loads its saved counts into one input per bay in `wash_cam.config.BAYS`: Bay 0 through Bay 4 and Vacuum 0. Previous image and Next image move through timestamp filename order. Both buttons save the current counts before navigation. Failed saves keep the current image open. The dropdown remains available. Previous image is disabled at the first image. Next image wraps from the last image to the first. Images without a database record inherit the last counts saved in the browser tab. Existing metadata always takes priority. Missing or invalid stored counts default to zero. Bay 0 receives focus on load. Space increments the count and advances focus. Tab preserves the count. Enter saves and opens the next image. The page does not refresh automatically. Save verified labels writes every bay's nonnegative integer count to `db/labels.sqlite3`. Each save replaces that image's metadata and updates its verification time.

The Werkzeug development server serves `/latest.jpg` and selected captures at `/image?image_path=<filename>`. `GET /api/labels?image_path=<filename>` returns saved metadata and verification time, or `null`. `POST /api/labels` accepts JSON with `image_path` and a `counts` object mapping every bay ID to its count. Responses disable browser caching. Image routes accept only existing JPEGs directly inside `tmp/images/`. The server closes each database connection after use. Browser refresh remains separate from server reload. The labeling tab preserves its current inputs until the user navigates or refreshes. The dashboard does not capture images.
