# Agent labeling

Humans no longer hand-label; a labeling agent with its own vision model does, and the detector never informs its labels. `wash-cam label-export --start "YYYY-MM-DD HH:MM" --end "..." [--every N]` (on the server) selects captures by their local-time filenames in `[start, end)` and writes `tmp/label_batches/<start>_<end>/` containing `overlay/<image>.jpg` (the capture with bay quads and IDs drawn by `wash-cam bays`), `manifest.json`, and an empty `labels.jsonl`. The manifest lists each frame's `image_path`, `local_time`, `raw` (absolute path of the original capture in `tmp/images/`, not copied), and `overlay` (relative to the batch), plus the bay quads with their `kind` (`wash`/`vacuum`) and the detector's `count_rule`: a vehicle counts for a bay when its ground contact point (bottom-center) is inside the quad. An existing batch is never replaced, because it may hold labels in progress. Keep `--every 1` for session tuning, which needs consecutive frames.

The labeler writes one JSON object per line to `labels.jsonl`: `image_path`, `counts` (bay ID to non-negative integer; omit any bay it cannot judge rather than guess), `labeled_by` (required, starting `agent:`, e.g. `agent:StormyCliff/gpt-6`), and optional `uncertain_bays` and `notes`. Judge vehicles from the raw image; the overlay only locates the bays.

`wash-cam label-import <batch>/labels.jsonl` validates every line first (known capture filename that exists, known bay IDs, non-negative integer counts, `agent:` provenance) and imports nothing if any line fails, naming each bad line. It writes `image_labels.metadata` as `{"vehicles": {"bays": [...]}, "labeled_by", "batch_id", "uncertain_bays", "notes"}` with `verified_at` set to the import time. Rows without `labeled_by` came from a human and are skipped, never overwritten; an agent's earlier rows are replaced. `wash-cam evaluate` and `wash-cam score-sessions` take `--labels agent|human` (default `agent`) and print the source they scored against; scores against agent labels measure agreement with the labeling agent, not accuracy.
