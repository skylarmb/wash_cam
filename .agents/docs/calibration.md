# Calibration

The camera is re-seated between setups, so captures land off the framing `CAMERA_CROP_BOX` was tuned for. `wash-cam calibrate` corrects this once per setup rather than per frame: it captures a frame, matches ORB features against the stored reference frames, solves for a partial affine transform (translation, rotation, uniform scale) with RANSAC, and writes the result to `config.yaml`. Every later capture reuses that stored transform, so framing stays fixed — and identical, with no frame-to-frame jitter — until the user re-calibrates. Verified on hardware: after physically moving the camera, a 62x170 px displacement was corrected to a 3 px residual.

One reference is kept per lighting condition in `calibration/references/<name>.jpg`, because a scene looks too different between day and night to match across the two — a night capture matched against a daytime reference yielded 4 inliers and an 809 px error. Rather than classifying the capture, `align_to_best_reference()` tries every reference and keeps the highest inlier count, so no brightness threshold or twilight special case is needed. Matches below `MIN_CALIBRATION_INLIERS` are refused outright rather than stored, since a weak match produces a transform that would silently mis-frame every later capture. Record references with `wash-cam calibrate --set-reference NAME`; the first one defines canonical coordinates, and later ones are warped through the existing calibration so all references agree on where the crop box points.

`take_picture()` calls `align_frame()`, which warps the frame into reference coordinates before `crop_to_box()` runs. An uncalibrated camera returns the frame unchanged, which is the correct transform for a camera still in the reference position. `crop_to_box()` rejects boxes that do not fit the frame instead of letting numpy silently truncate the crop or produce an empty array. `grab_frame()` discards `CAMERA_WARMUP_FRAMES` frames first: a camera that just powered up needs streaming time before auto-exposure converges, and without this the first capture after a power cycle was effectively black.
