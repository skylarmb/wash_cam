# Shared typed configuration

## Interface

Changed `load_config()` to accept no arguments. The module resolves `config.yaml` at the source checkout root. It returns a frozen `Config` dataclass with the required field `example: bool`. The loader validates the field before construction. `functools.cache` retains the first successful result for later calls. Failed loads remain retryable. The existing camera crop constant remains unchanged.

## Tests and documentation

Replaced explicit-path and dictionary tests with isolated temporary checkouts. Tests cover typed fields, immutability, cached object identity after file edits and deletion, retry after errors, and internal path resolution. Removed the abandoned per-path interface from the tests and current documentation. Updated README and the configuration briefing to describe `config.example`, shared settings, and restart requirements.

## Validation

Commands used `UV_CACHE_DIR=/private/tmp/wash-cam-uv-cache` to avoid the sandbox restriction on the default uv cache.

- Baseline: `uv run --locked pytest tests/test_config.py -q` passed all 16 original cases.
- Red: `uv run --locked pytest tests/test_config.py -q --tb=short` produced 14 expected behavioral failures and 11 passes before the loader change. There were no collection or import errors.
- Green: The same focused command passed all 25 configuration cases.
- Complete: `uv run --locked pytest -q` passed all 31 cases. `ruff check .`, `ruff format --check .`, and `git diff --check` passed.
- Build: `uv build` could not refresh setuptools metadata because DNS access was blocked. `uv build --offline` used the cached build dependency and built the source distribution and wheel successfully.
