# YAML configuration

## Interface and setup

Added `wash_cam.config.load_config(path=None)` and `ConfigError`. The default path is relative to the source checkout. Explicit paths support installed packages and tests. Each call reads UTF-8 YAML with PyYAML's safe loader. The loader requires a mapping with string keys and reports file, encoding, parsing, and format errors. Added PyYAML to the project dependencies and lockfile. Added `config.example.yaml`, ignored `/config.yaml`, and created the local copy without replacing existing settings. Documented setup and usage in README and the feature briefing.

## Compatibility

Camera code added after planning imports `CAMERA_CROP_BOX` from the existing configuration module. Preserved that constant and its value after the first full-suite run exposed the import dependency. Camera settings remain outside YAML in this change. The example contains only `example: true`.
