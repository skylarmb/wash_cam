# Camera tests

Added `tests/test_camera.py` covering `take_picture()` (default and explicit camera index, cropping, RuntimeError on open/read failure, camera always released) and `run()` (prints the saved filename). Added a `camera` dispatch test and a `camera --help` case to `tests/test_cli.py`.

Per AGENTS.md's TDD exception for tests documenting existing behavior, these started green rather than red/green, since the camera module was already implemented and merged. Mocked the webcam by monkeypatching `cv2.VideoCapture` with a small `FakeVideoCapture` (isOpened/read/release) rather than a mocking library, matching the plain-pytest style already in use. Added `numpy` as an explicit dev dependency (previously only a transitive dependency of opencv-python) since tests build a real small frame array to verify crop slicing rather than mocking it away.

Validation passed: full pytest suite (14 passed), Ruff lint and format, `uv build`, `git diff --check`.
