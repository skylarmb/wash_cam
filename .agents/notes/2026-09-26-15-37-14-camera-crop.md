# Camera crop

Added `wash_cam/config.py` holding `CAMERA_CROP_BOX`, a hardcoded `(left, top, right, bottom)` pixel box. `take_picture()` now crops each frame to that box before saving.

The box values were derived from a user-drawn selection (screenshot of Preview's markup tool over a captured frame) isolating the wash bays, translated from screenshot pixel coordinates into the 1920x1080 capture frame. Validated by cropping the user's original capture and a fresh live capture with the resulting values and confirming visually that the crop matches the intended selection.

This is a first cut at externalizing tunable values into `config.py`; expect this module to grow as more hardcoded values need to move out of code.
