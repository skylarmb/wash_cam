# Camera capture

Added `wash_cam.camera` with `take_picture()`, following the `dummy` package pattern (interface exposed via `__init__.py`). Added `opencv-python` via `uv add`.

Found and fixed a bug during manual testing: the initial filename used second-level timestamp precision, so two captures within the same second silently overwrote each other. Switched to microsecond precision.

Tested against real hardware: this dev machine has four camera devices (FaceTime HD, Studio Display, Logitech Brio 101, iPhone continuity camera). Camera index 0 resolves to the Brio and is already aimed at the target car wash, so it works as the default without extra selection logic. Index mapping is not guaranteed portable across machines/OSes.

Validation passed: Ruff lint and format, manual capture against the real webcam after macOS camera permission was granted to the terminal.
