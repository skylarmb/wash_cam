# Vacuum bay and ID-keyed counts

Added the vacuum station as region `vac_0` (bottom-left corner, quad down to the frame edge at y=340 so a car clipped by the crop still counts; the user chose not to widen the crop). Replaced positional `BAY_POLYGONS` with `BAYS`, a mapping from label bay ID to quad. `assign_to_bay` returns the ID; `count_vehicles`, predictors, labels, and scoring use `{bay_id: count}`. The dashboard renders one input per `BAYS` entry (titled Bay 0-4 and Vacuum 0), `POST /api/labels` takes `counts` as an object with exactly the configured IDs, and the browser memory of previous counts is keyed by ID under a new sessionStorage key. No schema migration; the database had no rows.
